# Bitcount Prop Double (reference)

Flip Note glyphs are **hand-crafted** in `src/flipNote/glyphs.ts`, styled after [Bitcount Prop Double](https://fonts.google.com/specimen/Bitcount+Prop+Double) (double-pixel stems, proportional widths).

This font file is kept for reference only. The runtime does not render it.

```bash
npm run generate:font -w @pixopen/renderer  # validates glyph set
```
