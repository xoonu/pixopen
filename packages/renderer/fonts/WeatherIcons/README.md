# Weather Icons (Erik Flowers)

Flip Note–style soft weather sprites are baked from this icon font for the Pixoo weather frame.

- Font: [Weather Icons](https://erikflowers.github.io/weather-icons/) by Erik Flowers
- File: `weathericons-regular-webfont.ttf`
- Icons: SIL Open Font License 1.1
- Code / CSS in upstream: MIT

Regenerate soft sprites after changing size or glyph map:

```bash
npm run generate:weather-sprites -w @pixopen/renderer
```
