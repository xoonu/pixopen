# Bitcount Single (Flip Note glyphs)

Flip Note uses [Bitcount Single](https://fonts.google.com/specimen/Bitcount+Single) — a dot-matrix font where each character is a **5×7 grid of dots**.

- Font file: `BitcountSingle.ttf` (variable font from Google Fonts)
- License: [SIL Open Font License 1.1](OFL.txt)

Regenerate glyph dot patterns:

```bash
npm run generate:font -w @pixopen/renderer
```
